Privacy Policy

Last updated: October 9, 2026

Mililoli Refs ("the app") is a private tool operated by the owner of the Mililoli channel for personal production work.

Data the app accesses

With the user's permission, the app uses the Google Drive API to read reference images from, and save generated images to, folders in the user's own Google Drive.

How data is used

Files are used only to generate images for the user. The app does not sell, share or transfer Google user data to third parties, and does not use it for advertising.

Storage

OAuth tokens are stored only on the owner's server. Generated images are stored in the user's Google Drive.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.
